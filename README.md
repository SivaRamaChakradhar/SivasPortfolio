## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/sivaramachakradhar/SivasPortfolio.git
```

### Navigate to Project Folder

```bash
cd SivasPortfolio
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

### Start Production Server

```bash
npm start
```

### Docker (Optional)

Build and run the Docker image:

```bash
docker build -t sivasportfolio:1.0 .
docker run -p 3000:3000 sivasportfolio:1.0
```
